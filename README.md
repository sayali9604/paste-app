# 📝 Paste Sharing App

A simple web application that allows users to create, update, and view text pastes — similar to Pastebin. Built using **React**, **Redux Toolkit**, and **React Router DOM**.

---

## 🚀 Features

- 🔐 **Create new pastes** with a title and content
- ✏️ **Edit existing pastes**
- 👁️ **View paste in read-only mode**
- 💾 **LocalStorage support** for persistence
- 🔍 **Search pastes** by title
- 📋 **Share paste link**
- 🧼 Clear all or remove individual pastes (coming soon)

---

## 🛠️ Tech Stack

- **Frontend**: React + TailwindCSS
- **State Management**: Redux Toolkit
- **Routing**: React Router DOM
- **Notifications**: React Toastify
- **Persistence**: LocalStorage
